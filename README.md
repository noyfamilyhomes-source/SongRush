SongRush is the first product within the broader CrowdPulse vision. It has been designed as a live audience song request platform that allows patrons to request songs during live performances using their phones, while creating a new revenue stream for performers and venues.
The long-term vision extends beyond musicians into DJs, sporting clubs, charities, entertainment venues and other live events.

View the https://github.com/noyfamilyhomes-source/SongRush/wiki pages for more information.
